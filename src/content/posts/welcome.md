这是「老锦的代码与诗」的第一篇文章。网站还在不断建设中，内容会陆续补齐。

## 这个网站是怎么来的

我不想要服务器，也不想折腾域名，于是把所有东西都放在 GitHub 上。文章是普通的 Markdown 文件，部署走 GitHub Pages，成本为零。

## 会写些什么

主要拿来发布技术博客、未来规划还有其他的一些内容创作。
除此之外，也会少量发一些设计、生活记录，思维碎片，影视剧分享。
更新不一定频繁，但每一篇都会认真对待。
